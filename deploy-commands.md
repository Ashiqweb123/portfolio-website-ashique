# Netlify Redeployment Commands

## If you have GitHub connected to Netlify:

```bash
# 1. Add all new files
git add .

# 2. Commit your changes
git commit -m "Add typing animation and custom icons"

# 3. Push to GitHub
git push origin main
```

## If you want to deploy manually:

```bash
# 1. Build the project
npm run build

# 2. Go to netlify.com
# 3. Find your site
# 4. Drag the 'build' folder to redeploy
```
